# Interactive Card Details Form

A responsive and interactive credit card details form built with HTML, CSS and JavaScript.

![Interactive Card Details Form](./screenshot.png)

## 📌 About The Project

This project is based on the **Interactive Card Details Form** challenge from Frontend Mentor.

The goal was to recreate the provided design and add interactive functionality using JavaScript.

The form allows users to enter their card details and see the information update on the card in real time.

## ✨ Features

- Responsive design for mobile and desktop
- Real-time card preview updates
- Cardholder name validation
- Card number validation
- Expiry date validation
- CVC validation
- Error messages for invalid inputs
- Interactive form submission
- Completed state after successful submission
- Form reset after clicking the Continue button
- Hover, active and focus states
